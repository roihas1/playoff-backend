EntityCurrentNew

Round / formatRound — fixed 4-value NBA enum, same Bo7 for every roundTournamentRound — label + bestOf per round; Bo1/Bo3/Bo5/Bo7, independent per round

GroupingConference — East/West/Finals, required enum on Team and SeriesGroup + GroupMembership — real entity for round-robin teams; Conference becomes an optional label
StandingsNoneGroupStanding — computed points/W/D/L per team, drives advancement
Champion / MVP guessingConferenceFinalGuess / ChampionTeamGuess / MVPGuess — 3 fixed region slots, hardcoded per stage nameStagePredictionConfig — admin-defined list of slots (0..N); same guess entities, generic count
